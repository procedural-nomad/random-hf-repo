# Random Hugging Face Repo

Uniform random selection across a frozen snapshot of all anonymously visible Hugging Face models, datasets and Spaces.

Every indexed repository gets exactly the same probability.

## Use
1. Settings → Pages → Source: GitHub Actions
2. Actions → Rebuild & deploy snapshot → Run workflow
3. Open the deployed Pages URL
4. On Android: Chrome → Add to Home screen

Run the workflow again whenever you want to refresh the snapshot.
